# Vitest Configuration

The server uses Vitest for testing. Tests are located in `src/git/__tests__/`.

## Running Tests

```bash
# Run all tests once
npm test

# Run tests in watch mode (recommended during development)
npm run test:watch

# Run tests with coverage report
npm run test:coverage
```

## Test Structure

- Tests use Vitest API (compatible with Jest)
- Console output is suppressed in tests to reduce noise
- External dependencies (simple-git, db) are mocked
- Tests use proper 40-character git commit hashes in mocks

## Writing Tests

1. Place test files in `src/git/__tests__/` directory
2. Use `.test.ts` or `.spec.ts` extension
3. Mock external dependencies with `vi.mock()`
4. Use `vi.fn()` for creating mock functions
5. Follow the existing test patterns

## Coverage

Coverage reports are generated in the `coverage/` directory when running `npm run test:coverage`.
